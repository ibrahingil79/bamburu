DESCRIPCIÓN
-----------
Bamburu es una plataforma de comercio electrónico y gestión empresarial de código
abierto, diseñada como alternativa gratuita a Shopify. Incluye un panel de
administración (ERP) completo y una tienda pública para clientes.

TECNOLOGÍA
----------
  Runtime:       Node.js 20+ (ES Modules)
  Framework:     Hono v4 + @hono/node-server
  Base de datos: SQLite (better-sqlite3 v9) — modo WAL, foreign keys ON
  Frontend:      SSR puro (template literals HTML, sin framework JS)
  Gráficas:      Chart.js v4 via CDN
  Autenticación: Sesiones en memoria (Map), cookies HttpOnly, SHA-256

INICIAR EL SERVIDOR
-------------------
  npm start          → node index.js  (puerto 3000)
  npm run dev        → node --watch index.js (recarga automática)

  Admin:   http://localhost:3000/admin
  Tienda:  http://localhost:3000/store

  Credenciales por defecto:
    Email:      admin@bamburu.com
    Contraseña: Admin1234
  (cambiarlas en /admin/users tras el primer acceso)

FLUJO DE PEDIDO
---------------
  ONLINE (tienda):
    pending → processing → shipped → delivered → completed
                                               ↘ cancelled
    Cualquier estado → refunded (al registrar reembolso)

  POS (admin):
    Se crea directamente como "completed" (venta presencial cobrada en caja)

SESIONES Y AUTENTICACIÓN
-------------------------
  Admin:    Cookie "asess" (HttpOnly, SameSite=Lax, 24h)
            Middleware adminAuth aplicado a todas las rutas /admin y /api/erp
  Cliente:  Cookie "csess" (HttpOnly, SameSite=Lax, 7 días)
            Gestionado manualmente en rutas de cuenta de la tienda
  Passwords: SHA-256 con prefijo "bamburu_2026_" (función hashPassword en core/auth.js)
